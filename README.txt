A LITTLE WORLD JUST FOR YOU - Birthday Website

HOW TO USE
1. Keep index.html, script.js, three-scenes.js and the assets folder together.
2. Open index.html in a browser, or upload all files to your GitHub repository.
3. For GitHub Pages, open Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Three.js loads from a CDN, so an internet connection is needed for the real-time 3D cake and sunset scenes.

CUSTOMIZE
Open script.js and edit the CONFIG object at the top:
- herName: her name
- passcode: the secret code
- intro: opening message
- musicFile: path to your song
- memories: photo paths and captions
- gifts: gift titles and messages
- letter and finalMessage: your personal words

PHOTOS AND MUSIC
Create an assets folder beside the HTML file. Add memory-1.jpg through memory-6.jpg and your-song.mp3, or change the paths in script.js to match your filenames.

IMPORTANT
The passcode is a playful surprise gate, not real security. Do not put private or sensitive information on a public website. The 3D visuals use Three.js via a public CDN and need internet access.
